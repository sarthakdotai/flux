# Flux brand

Reference board: [brand-board.webp](brand-board.webp)

- Wordmark: lowercase heavy "flux" with an asterisk (*) top-right. Tagline: "EMAIL FOR WHAT'S NEXT." (tracked caps).
- Asterisk is the brand element: app icon, list markers, decoration.
- Type: Suisse Intl (commercial licence; pick a stand-in until licensed).
- Colours:
  - Lime `#DFFF3B` (primary accent: active tab, compose / send buttons)
  - Bubblegum `#FF8EDC`
  - Tangerine `#FF5A1F`
  - Sand `#F5F4EF` (light background)
  - Onyx `#0B0B0B` (dark background, text)
- Screens on the board:
  - Dark sidebar: Inbox / Starred / Snoozed / Sent / Drafts / More, coloured-dot folders, lime + button, bottom tabs Mail / Calendar / Notes.
  - Light inbox: Primary / Social / Promotions pills, avatar rows (sender, subject, preview, time), lime compose button.
  - Dark compose: To field, large headline-style text, lime send button.
